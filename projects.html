02 | Authorized assessment

AutoVA

An authorized-only automated vulnerability assessment framework that coordinates reconnaissance and scanner stages into a single assessment pipeline.

What it does

Combines DNS and TLS reconnaissance with Nmap, Subfinder, httpx, WhatWeb, Nikto, and Nuclei; normalizes findings, summarizes risk, stores assessment data in SQLite, and produces JSON and HTML reports.

Implementation & safeguards

Requires explicit authorization confirmation before active tools run, restricts the target to one hostname or IP, uses conservative limits and process timeouts, and reports failures or incomplete stages explicitly.

03 | API security

API Security Assessment Toolkit

A modular Python and React assessment framework for APIs that the tester owns or has permission to assess. It supports both a command-line workflow and a web dashboard.

What it does

Analyzes OpenAPI specifications and endpoints, authentication and authorization behavior, BOLA/IDOR, CORS, security headers, HTTP methods, rate limits, and JWT metadata.

Implementation & safeguards

Uses bounded, non-destructive checks, distinguishes confirmed findings from potential issues and observations, and produces sanitized HTML, Markdown, and JSON evidence without storing credentials or raw response bodies.

A classroom engagement platform that combines live class sessions with real-time student attention indicators and post-session analytics.

05 | Reconnaissance

Power Lens

A command-line reconnaissance tool for domains the operator owns or is explicitly authorized to assess.

What it does

Discovers subdomains with Subfinder, probes hosts with httpx, checks ports with Nmap, retrieves archived URLs with gau, and reviews TLS with testssl.sh. Results are presented in a grouped terminal dashboard.

Implementation & safeguards

Designed around authorized targets. The project documentation describes bounded host checks, request timeouts, rate limits, and actionable reporting for missing tools and failures.

06 | Application security

Web Application Security Testing Lab

A controlled practice environment for learning and documenting common web application weaknesses using deliberately vulnerable applications.

What it does

Explores OWASP Top 10 issues in DVWA and OWASP Juice Shop, with manual testing using Burp Suite. Topics include SQL injection, cross-site scripting, and insecure direct object references.

Implementation & safeguards

Keeps testing within lab applications and focuses on structured findings, proof-of-concept context, and remediation guidance rather than claiming production assessments.
